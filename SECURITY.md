# Security

NeuroProfile Web is designed to process score data in the browser. The application does not intentionally transmit clinical data to an application server, analytics service, or third-party API.

Please do not report security vulnerabilities by opening a public GitHub issue. Use a private security-reporting mechanism associated with the repository when one is available.

Do not include patient identifiers, protected health information, screenshots containing clinical information, or confidential institutional data in issues, pull requests, parser examples, or test fixtures.

If you are evaluating NeuroProfile Web for clinical deployment, perform your organization's required security and privacy review. A client-side application can reduce data transmission risk, but it does not replace institutional controls for workstation security, browser configuration, hosting, access control, or protected health information.
