# Source components

NeuroProfile Web is intentionally distributed as a single `index.html` file so it can run without a build system or external runtime dependencies.

The files in this directory are readable feature-layer sources used during development. They are kept separately to make the parser, figure layout, typography, color, and application enhancements easier to inspect and test.

The source layers are not independently executable. `index.html` is the canonical distributable application.
