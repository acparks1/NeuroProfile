# Changelog

## 0.16

- Removed the redundant Profile selector.
- Synchronized the Test score legend with Individual score markers.
- Added a compact non-Theater Copy to Clipboard control.
- Added score-row insertion and deletion.
- Improved parser recognition of clinical report layouts, including Raw/T-score tables and TMT Part A notation.
- Consolidated the interface into Input, Layout, Appearance, and Export sections.
- Added independent figure typography controls and five local font presets.
- Added customizable color themes, including grayscale.
- Added Theater Mode with temporary markup and laser-pointer tools.
- Added multi-assessment longitudinal visualization.
- Added selectable X-axis metrics and standardized-score spacing.
- Changed aggregation to equal-weighted domain averages and an equal-weighted overall cognitive profile.
