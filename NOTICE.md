# Third-party notices

NeuroProfile Web bundles third-party JavaScript libraries so that the standalone application can operate without external network requests.

## JSZip

JSZip 3.10.1 is bundled for reading spreadsheet ZIP containers.

Project: https://stuk.github.io/jszip/

## pako

pako is bundled as a dependency of JSZip for compression and decompression.

pako is distributed under the MIT License. Its original license notice is preserved in `index.html`.

Project: https://github.com/nodeca/pako
